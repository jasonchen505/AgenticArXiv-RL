# 项目总结

## 判断与定位

足以写入简历，推荐名称：**论文工具 Agent 后训练复现与推理效率研究**。已经完成真实优化器更新、模型权重验证、数据隔离、匹配控制、留出评测和系统成本实验。它属于研究型后训练项目，尚不是可靠的生产论文助手，也没有证明 DPO/GRPO 稳定提高真实任务完成率。

## 问题与贡献

上游提供 ReAct 论文工具环境和 SFT→DPO→GRPO 等训练路径。原作者快照、全部权重与完整视觉后端不可得，因此先重建可审计的离线真实论文环境，明确抽取式图表/正文替代的复现边界。

在此基础上完成：

1. 本地 1.5B QLoRA/SFT，审计训练父任务与留出任务分离，区分 4,776 语言变体与 137 语义实例；记录预算、适配器、参考模型与损失掩码。
2. DPO、真实失败偏好、GRPO 与保持项实验，加入继续 SFT、同种子、学习率为零等控制。检查权重确实变化、参考模型冻结，保留 OOM、操作失败和负结果。
3. 修正 pass¹/pass³、观察截断的奖励计分、零方差组与完成状态口径；将“工具序列成功”推进到原始用户请求、真实证据、论文范围、故障恢复及全部成本。
4. 公共论文身份可确定时省略模型规划；复杂指称真实回退，确定执行器只根据实际工具反馈取同版本证据。完整原请求进入最终选证模型，私有评分项不进入运行时。
5. 同模型同思考模式配对验证，完整记录输入、思考、最终输出和失败 token；把冻结研究协议提取为独立可运行接口，并对 24 条既有轨迹验证语义一致。

## 关键实验

| 实验 | 真实工作与控制 | 结论 |
|---|---|---|
| QLoRA/SFT | 4,776 行、597 优化器步，NF4/bf16、LoRA r16；原始数据与适配器 SHA 保留 | 真实后训练已完成；小 Dev 不能证明普遍泛化 |
| DPO vs 继续 SFT | 同 448 TRAIN 提示/顺序、51 步、两种子；继续 SFT 同 chosen 控制 | 新参数请求严格成功 DPO 45/66、45/66，控制 51/66、52/66；不推广 DPO |
| 原生 GRPO vs lr=0 | 两种子各 64 步/256 rollout，全部支持不筛组；lr=0 控制权重不变 | 学习组 392 张量变化，控制 0；未满足新程序收益与旧能力保持条件 |
| 完整计划监督 | TRAIN 结构转换、学习率零控制、预算与旧能力检查 | 学会部分规划格式，仍未达正式门槛；不把训练内收益当泛化 |
| Qwen3.5 正文调用对照 | 同权重、原生思考模式、提示、seed、取证和预算；8新正文请求 | 5/8→5/8，16→11 调用，94,116→82,580 全部 token；0胜0负，绝对质量未达门槛 |

原生 GRPO 学习率零组实际执行 backward/optimizer loop，但不属于学习收益；“权重变化”也不等于任务改进。早期 IID/OOD 标签存在模板/程序重合，后续审计纠正其解释，没有偷偷删题或改旧成绩。

## 最新系统实验的边界

8 条作者冻结的自然请求，复用六篇已知论文，每题四组正文问项并整合两篇证据；两次离线注入主源失败并实际恢复。5 条公共别名请求省规划，3 条真实回退。

思考压缩与两调用完整任务均 5/8、覆盖 23/32；无思考压缩 4/8、19/32、11 调用、30,669 全部 token。思考组两个答案未在 8K 预算内闭合，一个漏学习难度排序。取证预检还保留一条有正文缺口与 10 参考句超过 8 句容量的任务，照常计入分母。

两主臂最终证据池、最终 prompt 与最终生成 IDs 在全部八题一致，规划调用分别实际执行；这是受限条件下较清晰的编排证据。作者小样本、固定 seed、助手语义审阅和抽取式原句接口不能建立统计非劣或自由综述质量保证。无思考对照改变采样与预算，是配置包比较。

## 工程和复现

上游最新同步到 `088f129a8bd4690479dc2697ae36451205070717`；保留既有训练/评测修复，合并后 856 测试通过、7 跳过。最新 38 次生成的输入与各输出通道全部 CPU tokenizer 重放，776 历史保护项、13 执行源、14 模型缓存文件 SHA 验证；自有 GPU4/7 worker 已结束。

代码中的研究协议是从冻结函数源逐字提取，仅改模块导入；CPU parity 检查验证所有工具事件、选证输入和交付答案，未重跑模型来获得新成绩。公开模型缓存路径由 CLI 提供，私有 rubric 不进入接口。

## 后续研究方向

求职交付阶段结束追加小样本配方。若继续研究，先用新的自然正文任务解决公共问题取证与输出容量，再判断是否存在可学习的系统性选证错误；训练时保留能力保持、匹配 chosen 控制与独立最终确认。上游新 wrapper 产生不同字节指纹，只能证明语言视图/权重变化，不能算新增语义任务或泛化。
